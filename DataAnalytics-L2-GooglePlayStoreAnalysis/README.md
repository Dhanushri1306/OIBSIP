# Google Play Store Analysis

Level 2 – Task 4 | Oasis Infobyte Data Analytics Internship

## Project Overview
This project explores the Google Play Store ecosystem through data cleaning, exploratory data analysis, visualization and sentiment analysis of user reviews.

## Objectives
- Clean and preprocess app and review datasets.
- Analyze app categories, ratings, sizes and installation trends.
- Compare free and paid applications.
- Explore paid app pricing and estimate potential revenue.
- Analyze user review sentiment using TextBlob.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Plotly
- TextBlob
- Jupyter Notebook

## Key Findings
- FAMILY has the highest number of apps.
- The average app rating is 4.2.
- Approximately 92.6% of apps are free.
- COMICS has the highest positive review sentiment at 90%.
- FAMILY has the highest estimated revenue among paid app categories.

## Conclusion
The analysis provides insights into app distribution, pricing, ratings, installation patterns and user sentiment in the Google Play Store.

Note: Estimated revenue is calculated using listed app prices and installation counts. It does not represent actual developer earnings.
